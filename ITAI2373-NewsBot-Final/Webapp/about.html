About This Project

NewsBot Intelligence System 2.0

A web interface for the ITAI 2373 final project — an NLP platform that classifies, summarizes, and converses about news content.

Module A

Content Analysis Engine

TF-IDF + Logistic Regression classification with confidence scoring, LDA topic discovery, sentiment analysis, and named entity extraction.

Module B

Language Understanding & Generation

Summarization (extractive fallback or BART) and semantic search over the article corpus (TF-IDF or sentence-transformer embeddings).

Module C

Multilingual Intelligence

Automatic language detection, ready to extend with translation for cross-language comparison.

Module D

Conversational Interface

A lightweight intent layer under Ask NewsBot that parses category, sentiment, and summarize requests in plain English.
